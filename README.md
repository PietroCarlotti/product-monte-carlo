# Product Monte Carlo (PMC)

Product Monte Carlo (PMC) estimates expectations under a density proportional to a product of component densities using only samples from the individual components. PMC constructs consensus and discrepancy variables from independent component draws, fits the conditional expectation of a target function given the discrepancy, and evaluates that regression at zero discrepancy. This supports density-evaluation-free aggregation in settings such as distributed Bayesian inference and simulation-based inference.

This repository contains the Python PMC implementation, R fusion baselines, simulation and application pipelines, and the scripts and rendered figures used in the accompanying paper.

## Setup

### Python

PMC requires Python 3.10 or newer. Install the package and its declared runtime dependencies in editable mode from the repository root:

```bash
python3 -m pip install -e .
```

### R

The fusion baselines require R 4.4 or newer and the dependencies declared in [`src/fusion/DESCRIPTION`](src/fusion/DESCRIPTION). The package is loaded in place rather than installed globally. After installing those dependencies, verify the package with:

```bash
Rscript -e 'devtools::load_all("src/fusion")'
```

## Data

External data are stored under `data/raw/`, processed data under `data/processed/`, and application results under `data/results/`.

- **Respiratory:** a longitudinal clinical-trial dataset used for the privacy-restricted aggregation application.
- **HIGGS:** a large binary-classification dataset with 28 predictors used for the large-scale inference application.
- **MAGIC:** a binary-classification dataset with 10 measured features used for an additional large-scale inference experiment.

The shared download script fetches only HIGGS and respiratory:

```bash
bash src/data/fetch_raw_datasets.sh
```

MAGIC is downloaded and prepared separately:

```bash
python3 src/data/prepare_magic.py
```

## Reproducibility and navigation

- `experiments/outputs/` contains study-specific configurations and curated simulation results.
- `experiments/scripts/launcher.sh`, `launcher.py`, and `launcher.R` provide the shared experiment launchers.
- `src/applications/` contains the respiratory, HIGGS, MAGIC, and downstream HSP90 application pipelines.
- `artifact/scripts/` contains the plotting scripts used for the paper figures.
- `artifact/figures/` contains the rendered paper figures for direct inspection.

## Paper figures

Run the plotting commands from the repository root after completing the Python setup. The following commands regenerate the figures from the released results and write them under `artifact/figures/`:

```bash
python3 artifact/scripts/product_distribution_plot.py
python3 artifact/scripts/pmc_ppc_curvature.py
python3 artifact/scripts/convergence_plots.py --family all
python3 artifact/scripts/convergence_plots.py --family ols-dimension-scaling
python3 artifact/scripts/calibration_plots.py
python3 artifact/scripts/hsp90_plots.py
```

The product-distribution figure additionally requires a working LaTeX installation. The PMC-GP overlap diagnostic is generated by its experiment script and can be rerun with:

```bash
PYTHONPATH=src python3 \
  experiments/outputs/gaussian/univariate/gp_overlap_posterior_variance/overlap_posterior_variance.py \
  experiments/outputs/gaussian/univariate/gp_overlap_posterior_variance/config.json \
  --output-dir artifact/figures/calibration
```

This last command refits the configured Gaussian processes and can be substantially more expensive than the plotting-only commands. The released configuration uses CUDA; set its `device` field to `cpu` to run without a GPU, at a higher runtime. The released result and rendered figure are already provided.

## HSP90 simulation-based inference

This experiment combines K = 10 noisy images of a protein. A neural posterior gives an image-level posterior for one shape parameter, and PMC combines the K image-level posteriors into a posterior for that parameter. The Oracle is MCMC on the product of the image-level posterior densities.

The external image simulator, simulator-dependent training and Oracle code, and trained posterior network are not distributed. This artifact provides the saved image-level posterior draws in `data/results/hsp90/sbi/posterior_draws.npz`, the reported results under `data/results/hsp90/`, and the downstream PMC and diagnostic scripts needed to reproduce the corresponding summaries. Run the following commands from the repository root.

1. Fit the PMC OLS, MLP, and GP estimators to the saved draws. This writes `pmc_ols_moments.json`, `pmc_mlp_moments.json`, and `pmc_gp_moments.json`. The `--device` option (`cpu` by default, or `cuda`) sets the device for the MLP and GP fits; OLS always runs on the CPU.

   ```bash
   PYTHONPATH=src python3 src/applications/run_hsp90_pmc.py \
     data/results/hsp90/sbi/posterior_draws.npz \
     data/results/hsp90/pmc \
     --device cpu
   ```

2. Compute the tail and KDE-product diagnostics. This reads `posterior_draws.npz` and `pmc_mlp_moments.json` and writes `tail_diagnostics.json` and `kde_product_check.json`.

   ```bash
   python3 src/applications/run_hsp90_diagnostics.py \
     data/results/hsp90/sbi/posterior_draws.npz \
     data/results/hsp90/pmc/pmc_mlp_moments.json \
     data/results/hsp90/diagnostics
   ```
